# 提示词库（点击插入）

> **这个包现在有三个节点**，同属 `提示词工具` 分类：
> **提示词库（点击插入）**（本文件讲的就是它）、**H3 提示词助手**、**生图提示词助手**。
> 后两个是调语言模型把口语描述改写成提示词的节点，代码在 `llm_nodes/`，
> 文档见 [`llm_nodes/README.md`](llm_nodes/README.md)。本文件只讲词库节点。

一个内置中英对照词库的 ComfyUI 提示词节点：**上方文本框直接输出 prompt，下方词库做成抽拉式抽屉**。

- 输出是 STRING（`text`），**直接连线**到任意节点的文本/STRING 输入（如 `CLIPTextEncode` 的 text），连上即用，无需复制粘贴
- 抽屉收起时只留"提示词库"一条把手（节点下方无空隙），展开时内容向下展开、把手位置不动
- 点词条 = 选中（高亮 + 写入文本框），**再点一次 = 取消选择（从文本框移除）**，手动编辑文本框时高亮自动同步

## 使用方法

1. 在工作流里添加节点：右键 → Add Node → `提示词工具` → `提示词库（点击插入）`
2. 把节点的 `text` 输出**直接连线**到 `CLIPTextEncode` 的 text 输入（或任何接受 STRING 的节点输入）
3. 在节点上：
   - 点"提示词库"把手展开 / 收起词库
   - **点分类标签**（画质 / 人物 / 服饰 / 场景……）切换词库，分类栏可横向滚动
   - **搜索框支持中文**：输入"双马尾"、"星空"、"逆光"等中文即可搜到对应英文 tag
   - **点词条**选中（高亮 + 追加进上方文本框），**再点一次取消**（自动从文本框移除，不会重复追加）
   - **全选本类**按钮：一次把当前分类的全部词条加入文本框（适合负面词整类点上）
   - 每个分类末尾有个 **＋** 按钮，可直接在节点里新增词条，不用去改 JSON
   - 文本框可直接手动编辑，删掉某个词后对应词条高亮会自动熄灭
   - **清空**按钮一键清空文本

收起状态会随工作流一起保存/恢复。负向提示词再放一个本节点，用"负面"分类即可。

## 权重：让某个词更起作用

提示词里每个词的影响强度可以单独调节，写法是 `(词:倍数)`：

| 写法 | 含义 |
| --- | --- |
| `smile` | 默认强度，就是不写权重 |
| `(smile:1.3)` | 让"微笑"更明显一些 |
| `(smile:0.7)` | 让"微笑"弱一些，若有若无 |

> 不用数字也能用：`(smile)` 等于 1.1 倍，`[smile]` 是 0.9 倍，这是 ComfyUI / SD 的通用写法。

在节点上的操作方式（不用手打括号）：

| 操作 | 效果 |
| --- | --- |
| **Shift + 点词条** | 逐级加强：1 → 1.1 → 1.2 → 1.3 → 1.5 → 回到 1 |
| **Alt + 点词条** | 逐级减弱：1 → 0.9 → 0.8 → 0.7 → 0.5 → 回到 1 |
| **右键点词条** | 权重归 1（保留这个词，去掉加强/减弱） |

调过权重的词条，按钮右上角会显示当前倍数（如 `1.3`），一眼能看出来。手动在文本框里写 `(smile:1.3)` 也能被正确识别和高亮。

什么时候用得上：想让"金发"更浓一点、让"背景虚化"别太强、让某个元素不要抢主体——都是调权重而不是加词。

## 预设：一键套用整套提示词

分类栏最前面是「预设」分类。把文本框调到满意的一套词，点预设页的 **＋ 保存当前文本为预设**，起个名字（如"电影感人像"）即可。

- 点预设 = **并入**当前文本框，不覆盖已有内容（普通词去重追加，中文参数行合并进同一行）
- 预设按钮右上角 **×** 可删除
- 预设存在 `data/_presets.json`，不参与词库加载，随便改

## 词库构成：`data/` 下任意多个 JSON 文件

插件自动合并 `data/` 目录下的**所有** `.json` 文件，不限制数量、不限制文件名。想加词库直接新建文件即可，不用改代码。

加载规则：

1. `tags.json` 是**基准文件**，最先加载，它的 `order` 决定分类栏排布
2. 其余文件按**文件名排序**依次并入，所以用 `10_` / `20_` / `90_` 这类数字前缀控制合并顺序（影响同一分类内词条的先后）
3. 以 `_` 或 `.` 开头的文件自动跳过 —— 备份和预设文件用这个规则避免被当成词库
4. 单个文件写错 JSON 只会跳过该文件并在控制台报错，不影响其余文件

### 两个负面分类的区别

这是刻意分开的，**不要混着点**：

- **负面**（58 条）——二次元向。画动漫图时点「全选本类」整类点上即可
- **写实负面**（40 条）——写实 / 摄影向。包含 AI 味（塑料肌肤、过度磨皮、假人感）和"排除非写实风格"的词（`anime`、`cartoon`、`illustration`、`3d render`……）

之所以分开：如果把 `anime` 这类词混进二次元的负面里，等于告诉模型"不要画动漫"，图会直接跑偏。画二次元只用「负面」，画写实只用「写实负面」。

全库每个词条只出现在一个分类里，搜索不会翻出重复项。

### 分类职责边界

新增词条时照此归类：

- **光照 = 光本身**（光源、方向、质感），**色调 = 画面色彩与后期**（饱和度、冷暖、对比度、暗角/HDR）
- **画风 = 怎么画**（媒介与技法），**氛围 = 什么感觉**（情绪形容词），**题材 = 画什么世界观**
- **场景 = 地点与背景**，天气、时间、季节不进场景
- **道具 = 手持/随身器物**，食物单独一类；**材质 = 面料与表面质感**，不混进服饰款式里

## 调整分类顺序与文件划分

- **分类栏顺序**以基准文件 `data/tags.json` 的 `order` 为准。新分类若已在 `order` 里预留过就插到对应位置，没预留则自动追加在「负面」之前；空分类不会显示
- **文件怎么拆不影响结果**，合并在运行时完成。想把某个分类单独拎出来，就新建 `xx_名字.json` 把词条搬过去；想合并就拷进同一个文件、删掉另一个

## 添加自己的词条

两种方式：

1. **在节点里加**（推荐）：切到目标分类，点网格末尾的 **＋**，填中文名和英文 tag，回车即可，自动写入 `99_自定义.json`
2. **直接改 JSON**：打开对应主题的文件，或新建一个 `96_我的词条.json`：

```json
{
  "我的常用": [
    {"t": "hatsune miku", "z": "初音未来"},
    {"t": "gosha_rokutosei", "z": "六等星notation"}
  ]
}
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| `t` | 实际插入提示词的文本（必填，同一分类内按此去重） |
| `z` | 显示和搜索用的中文名 |
| `z2` | 可选，额外的中文别名，也参与搜索 |
| `d` | 可选，说明文字，显示在按钮副行 |
| `cat` | 可选，中文参数行模式，值 = 行分类名（生成 `光源: 自然光；` 这种整行，适合 Z-Image / Qwen-Image 等中文模型） |

同一个分类的词条可以分散在多个文件里，会按文件顺序拼接，这是拆分大分类的常用办法。
